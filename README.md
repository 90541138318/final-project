2. Move into the project folder:
   ```bash
   cd <repo-name>
   ```

## Project Structure

```
final-project/
├── css/
│   ├── reset.css
│   └── styles.css
├── images/
│   ├── about-us.jpg
│   ├── bob.jpg
│   ├── digital.jpg
│   ├── john.jpg
│   ├── logo.png
│   ├── main-banner.jpg
│   ├── marketing.jpg
│   ├── print.jpg
│   ├── video.jpg
│   ├── vision.jpg
│   └── web.jpg
└── index.html
```

- **`index.html`** contains the full page markup.
- **`css/reset.css`** removes default browser styling so layouts look consistent across browsers.
- **`css/styles.css`** holds all custom styles: layout, typography, colours and responsive rules.
- **`images/`** contains the logo, banner, service images, team photos and section images.
